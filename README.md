# Pokédex

Pokédex web app that lets you browse, search and filter 1025 Pokémon using [PokéAPI](https://pokeapi.co/).
Created with vanilla JavaScript, HTML, and CSS.
Primarily made so I can get more practice with JavaScript.

## Features

- Browse all 1025 Pokémon from Generation 1 to Generation 9
- Search for a Pokémon by name
- Filter Pokémon by their type
- Clicking a Pokémon brings up a popup that shows more details (along with a Shiny toggle)
